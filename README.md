# cosmosSpace 🚀

My 11th assignment during the Front-End Development track at Route Academy.

A space dashboard built with JavaScript that uses APIs to display astronomy pictures, upcoming space launches, and information about the planets.

## ✨ Features

* Display NASA Astronomy Picture of the Day
* Load an astronomy picture by selecting a specific date
* Display upcoming space launches
* Explore planets and their information
* Display detailed planetary data
* Compare planets using different characteristics
* Dynamic content rendering using JavaScript

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* APIs
* Fetch API
* DOM Manipulation
